# 浏览器指纹伪装库 - 使用教程

## 🚀 快速开始

### 安装依赖
```bash
npm install playwright
```

### 基础使用 (推荐)
```javascript
const { chromium } = require('playwright');
const BrowserFingerprint = require('./lib/browser-fingerprint');

(async () => {
    const browser = await chromium.launch({ headless: false });
    
    // 创建带指纹伪装的上下文 - 一行代码搞定！
    const context = await BrowserFingerprint.createStealthContext(browser);
    const page = await context.newPage();
    
    // 正常使用，指纹已自动伪装
    await page.goto('https://bot.sannysoft.com/');
    
    await browser.close();
})();
```

## 📖 详细使用指南

### 1. 通用指纹伪装 (`BrowserFingerprint`)

#### 基础用法
```javascript
const BrowserFingerprint = require('./lib/browser-fingerprint');

// 方法1: 使用默认随机配置
const context = await BrowserFingerprint.createStealthContext(browser);

// 方法2: 自定义配置
const context = await BrowserFingerprint.createStealthContext(browser, {
    hardwareConcurrency: 8,
    deviceMemory: 16,
    platform: 'Win32'
});
```

#### 手动应用指纹伪装
```javascript
// 创建普通上下文
const context = await browser.newContext(BrowserFingerprint.getPlaywrightOptions());

// 应用指纹伪装
await BrowserFingerprint.applyToContext(context);

// 或者应用到单个页面
const page = await context.newPage();
await BrowserFingerprint.applyToPage(page);
```

#### 获取配置信息
```javascript
// 生成随机配置
const config = BrowserFingerprint.getRandomConfig();
console.log('生成的配置:', config);

// 获取伪装脚本
const script = BrowserFingerprint.getSpoofingScript(config);

// 获取 Playwright 选项
const options = BrowserFingerprint.getPlaywrightOptions(config);
```

### 2. 加州地区指纹 (`CaliforniaFingerprint`)

#### 基础用法
```javascript
const CaliforniaFingerprint = require('./lib/california-fingerprint');

// 创建加州指纹上下文
const { context, config } = await CaliforniaFingerprint.createCaliforniaContext(browser);

console.log(`使用加州指纹: ${config.region}`);
console.log(`硬件配置: ${config.hardwareConcurrency}核 CPU, ${config.deviceMemory}GB 内存`);
```

#### 批量生成加州指纹
```javascript
// 生成5个不同的加州指纹配置
const fingerprints = CaliforniaFingerprint.generateMultipleCaliforniaFingerprints(5);

fingerprints.forEach((fp, index) => {
    console.log(`${index + 1}. ${fp.region} - ${fp.hardwareConcurrency}核/${fp.deviceMemory}GB`);
});

// 使用特定配置
const selectedConfig = fingerprints[0];
const { context } = await CaliforniaFingerprint.createCaliforniaContext(browser, selectedConfig);
```

#### 自定义加州配置
```javascript
// 指定特定的加州配置
const customConfig = {
    hardwareConcurrency: 12,  // 高端配置
    deviceMemory: 32,
    region: 'Silicon Valley'  // 指定地区
};

const { context, config } = await CaliforniaFingerprint.createCaliforniaContext(browser, customConfig);
```

#### 地理位置功能
```javascript
// 获取随机加州坐标
const location = CaliforniaFingerprint.getRandomCaliforniaLocation();
console.log(`坐标: ${location.latitude}, ${location.longitude}`);

// 在页面中测试地理位置
const position = await page.evaluate(() => {
    return new Promise((resolve, reject) => {
        navigator.geolocation.getCurrentPosition(resolve, reject);
    });
});
console.log('获取的位置:', position.coords);
```

### 场景3: 多账号管理
```javascript
async function multiAccountManagement() {
    const browser = await chromium.launch({ headless: false });
    
    // 为每个账号生成不同的指纹
    const fingerprints = CaliforniaFingerprint.generateMultipleCaliforniaFingerprints(3);
    
    for (let i = 0; i < fingerprints.length; i++) {
        const { context } = await CaliforniaFingerprint.createCaliforniaContext(browser, fingerprints[i]);
        const page = await context.newPage();
        
        console.log(`账号 ${i + 1}: ${fingerprints[i].region} 指纹`);
        
        // 登录不同账号...
        await page.goto('https://platform.com/login');
        
        // 执行账号特定操作...
        
        await context.close();
    }
    
    await browser.close();
}
```

## 🐛 故障排除

### 常见问题

#### 1. 指纹伪装不生效
```javascript
// 确保在页面导航前应用伪装
await BrowserFingerprint.applyToContext(context);
const page = await context.newPage();
// 然后再导航
await page.goto('https://example.com');
```

#### 2. WebGL 信息显示异常
```javascript
// 检查配置是否正确
const config = BrowserFingerprint.getRandomConfig();
console.log('WebGL 配置:', config.webgl);

// 确保 WebGL 配置与平台匹配
if (config.platform === 'MacIntel') {
    config.webgl.vendor = 'Google Inc. (Apple)';
    config.webgl.renderer = 'ANGLE (Apple, Apple M1, OpenGL 4.1)';
}
```

#### 3. 地理位置获取失败
```javascript
// 确保授予地理位置权限
const context = await browser.newContext({
    ...CaliforniaFingerprint.getPlaywrightOptions(),
    permissions: ['geolocation']
});
```
