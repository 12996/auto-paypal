# 浏览器指纹伪装库使用教程

## 快速开始

### 安装依赖

```bash
npm install playwright
```

### 使用加州 baseline 指纹

```js
const { chromium } = require('playwright');
const CaliforniaFingerprint = require('./lib/california-fingerprint');

(async () => {
  const browser = await chromium.launch({
    headless: false,
    args: ['--lang=en-US']
  });

  const { context, config } = await CaliforniaFingerprint.createCaliforniaContext(browser);
  const page = await context.newPage();

  console.log('region:', config.region);
  console.log('locale:', config.locale);
  console.log('languages:', config.languages);

  await page.goto('https://bot.sannysoft.com/');
  await browser.close();
})();
```

## 加州 baseline 指纹

当前 `CaliforniaFingerprint` 默认固定为美国加州 San Diego Windows Chrome baseline。

关键输出：

```js
{
  region: 'San Diego',
  platform: 'Win32',
  hardwareConcurrency: 8,
  deviceMemory: 8,
  locale: 'en-US',
  languages: ['en-US', 'en'],
  timezone: 'America/Los_Angeles',
  screen: {
    width: 1920,
    height: 1080,
    availWidth: 1920,
    availHeight: 1032
  }
}
```

### 生成配置

```js
const config = CaliforniaFingerprint.generateRandomCaliforniaFingerprint({
  chromeVersion: '133.0.6943.16'
});
```

说明：当前为了真实性，`generateRandomCaliforniaFingerprint()` 会生成固定 baseline，而不是在多个地区/设备之间大幅随机。

### 创建 context

```js
const { context, config } = await CaliforniaFingerprint.createCaliforniaContext(browser);
```

该方法会自动：

- 读取真实浏览器 Chrome 版本。
- 对齐 UA 与 `sec-ch-ua`。
- 设置 `locale: en-US`。
- 设置 `Accept-Language: en-US,en;q=0.9`。
- 注入 baseline 指纹脚本。

## 强制英文语言

即使外部传入中文配置：

```js
const customConfig = {
  locale: 'zh-CN',
  languages: ['zh-CN', 'zh']
};
```

也会被强制归一为：

```js
locale: 'en-US'
languages: ['en-US', 'en']
```

浏览器内应验证为：

```js
await page.evaluate(() => ({
  language: navigator.language,
  languages: navigator.languages,
  intl: Intl.DateTimeFormat().resolvedOptions().locale
}));

// 期望:
// {
//   language: 'en-US',
//   languages: ['en-US', 'en'],
//   intl: 'en-US'
// }
```

## PayPal 英文/美国页面处理

在主流程 `index.js` 中，PayPal 语言不只靠指纹脚本，还额外处理：

1. 订单 API 请求头：

```txt
Accept-Language: en-US,en;q=0.9
```

2. PayPal document 请求头：

```txt
accept-language: en-US,en;q=0.9
```

3. PayPal URL 参数：

```txt
locale.x=en_US
country.x=US
lang=en_US
language=en_US
hl=en
```

4. PayPal cookie：

```txt
LANG=en_US%3BUS
cookie_check=yes
```

运行时会输出诊断日志：

```txt
[PayPal Locale] force en_US: oldUrl -> newUrl
[PayPal Locale] page={...}
```

如果页面仍显示中文，应检查日志中的：

- `url`
- `htmlLang`
- `navigator.language`
- `navigator.languages`

## 常见问题

### 1. PayPal 仍显示中文

先确认浏览器内 JS 指纹：

```js
navigator.language
navigator.languages
Intl.DateTimeFormat().resolvedOptions().locale
```

如果这些都是英文，但 PayPal 仍中文，优先查：

- PayPal URL 是否仍带中文 locale。
- PayPal cookie `LANG` 是否被服务端改回中文。
- 外部订单 API 返回的支付链接是否已绑定中文地区。
- 页面 `document.documentElement.lang` 是否为中文。

### 2. 修改代码后没有效果

必须重启 Node 进程和浏览器进程。已打开的 context 不会自动应用新的 init script 或 route 规则。

### 3. 不要给 geolocation 预授权

当前 baseline 不默认传：

```js
geolocation
permissions: ['geolocation']
```

原因是 PayPal 风控 iframe 可能读取 geolocation 权限状态。默认不预授权更接近 baseline。

### 4. 同一页面指纹为什么要稳定

Canvas / Audio 噪声使用 `fingerprintSeed` 生成稳定微扰。不要在每次读取时直接用 `Math.random()`，否则同一个页面内多次读取得到不同结果，反而不真实。

```bash
node --check lib/california-fingerprint.js
```

```bash
node --check index.js
node --check chatgpt.js
```

- 检查 PayPal 语言问题时保留 `[PayPal Locale]` 日志，不要只看页面截图。
