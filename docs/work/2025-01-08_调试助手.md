# 调试助手使用指南

## 概述

出错时自动保存 HTML → 离线调试 → 找到选择器 → 更新代码

## 文件

| 文件 | 作用 |
|------|------|
| `test/debug_helper.js` | 保存 HTML 的核心模块 |
| `test/test_debug_html.js` | 打开保存的 HTML 调试 |
| `debug_html/` | HTML 文件存放目录 |

## 使用流程

### 1. 代码中引入

```javascript
const debug = require('./test/debug_helper');
```

### 2. 出错时保存

```javascript
try {
    await page.locator('#login_email').fill(email);
} catch (e) {
    await debug.saveOnError(page, 'paypal_email');
    throw e;
}
```

### 3. 启用调试模式

```powershell
$env:DEBUG_MODE = "1"
node test/test_index.js "token"
```

### 4. 打开保存的页面调试

```powershell
node test/test_debug_html.js
```

### 5. 在浏览器 Console 中使用

```javascript
findEmail()        // 查找邮箱输入框
highlightInputs()  // 高亮所有输入框
find('#selector')  // 测试选择器
listAll()          // 列出所有可交互元素
```

### 6. 更新代码中的选择器

找到正确选择器后，更新 index.js 中对应的代码。

## 生产环境

不设置 `DEBUG_MODE` 环境变量，`saveOnError()` 直接返回，零开销。

## 去重机制

相同 URL 的页面只保存一次，避免重复。
