# 加州指纹检测脚本与 US 语言一致性

日期：2026-05-17

## 目标

- 提供一个可手动打开浏览器的指纹检测脚本。
- 代理写法参考 `chatgpt.js`，可直接在脚本文件顶部固定默认代理。
- 支持本地 HTTP 代理直连，也支持远程 SOCKS5 代理通过本地桥接。
- 避免用高风险字体 hook 强行改字体指纹，只保证语言、时区和请求头保持 US 一致。

## 使用方式

直接使用脚本顶部默认代理：

```powershell
node .\test\test_california_fingerprint.js
```

命令行覆盖代理：

```powershell
node .\test\test_california_fingerprint.js --proxy 127.0.0.1:7897
```

远程 SOCKS5 代理走桥接：

```powershell
node .\test\test_california_fingerprint.js --proxy "socks5://user:pass@host:3010" --local-port 10900 --vpn-port 7897 --vpn-type http
```

  - `navigator.language = en-US`

  - 页面正文未出现 `zh-CN` / `zh_CN`

## 注意

- 当前没有用 JS 强行隐藏字体列表里的中文字体名，因为改写 DOM/CSS/Canvas/FontFaceSet 测量行为容易导致指纹异常。
- 如果要求 `fonts` 里也不出现中文字体，应使用干净英文 Windows/Chrome 环境或移除系统 CJK 字体，而不是在页面 JS 层强行 hook。
