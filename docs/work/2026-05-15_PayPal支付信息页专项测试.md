# PayPal 支付信息页专项测试

## 问题/需求描述

需要一个可单独运行的测试脚本，从 PayPal 已提交邮箱、进入支付信息填写页之后开始验证表单渲染、字段填写和可选提交。

## 解决方案

新增 `test/test_paypal_payment_form.js`：

- 接收 PayPal signup URL 参数或 `PAYPAL_SIGNUP_URL` 环境变量。
- 复用加州指纹、Stealth、PayPal 英文 locale/cookie 处理。
- 如果页面仍停在 Create an Account 或邮箱输入页，会自动推进到支付信息页。
- 等待 `#cardNumber` 渲染期间会尝试处理 PayPal 滑块/验证按钮。
- 填写并校验卡号、有效期、CVC、姓名、邮箱、手机号、地址、州、邮编和 PayPal 密码。
- 默认只填表校验；加 `--submit` 后才点击 `Agree & Create Account`。

## 修改的文件及关键改动

- `test/test_paypal_payment_form.js`
  - 新增 PayPal 支付信息页专项测试入口。
  - 增加 `--submit`、`--headless`、`--keep-open` 参数。
  - 失败或完成时保存调试截图，`DEBUG_MODE=1` 时保存 HTML。

## 测试方法

语法检查：

```bash
node --check test/test_paypal_payment_form.js
```

运行示例：

```bash
node test/test_paypal_payment_form.js "<PayPal signup URL>" --keep-open
node test/test_paypal_payment_form.js "<PayPal signup URL>" --submit
```
