### 1. 核心架构设计

- **通用层** (`browser-fingerprint.js`) - 轻量级通用解决方案
- **地区层** (`california-fingerprint.js`) - 地区化专用解决方案  
- **高级层** (`fingerprint-spoofer.js`) - 功能完整的高级解决方案

## 使用示例

### 简单使用
```javascript
const BrowserFingerprint = require('./lib/browser-fingerprint');

// 一行代码创建隐身浏览器
const context = await BrowserFingerprint.createStealthContext(browser);
```

### 加州指纹
```javascript
const CaliforniaFingerprint = require('./lib/california-fingerprint');

// 创建加州地区指纹
const { context, config } = await CaliforniaFingerprint.createCaliforniaContext(browser);
console.log(`使用 ${config.region} 指纹`);
```
