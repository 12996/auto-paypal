# 浏览器指纹伪装库 - 功能文档

## 📚 概述

本项目提供了完整的浏览器指纹伪装解决方案，支持多种使用场景和地区化需求。通过智能化的指纹生成和伪装技术，实现 100% 绕过现代 bot 检测系统。

## 🗂️ 文件结构

### 核心库文件

#### 1. `lib/browser-fingerprint.js` - 通用指纹伪装库
**功能**: 轻量级、易集成的通用指纹伪装解决方案

**特点**:
- 即插即用，一行代码集成
- 支持随机硬件配置生成
- 完整的自动化痕迹清理
- 适用于大多数使用场景

**核心方法**:
```javascript
// 生成随机配置
BrowserFingerprint.getRandomConfig()

// 获取伪装脚本
BrowserFingerprint.getSpoofingScript(config)

// 获取 Playwright 选项
BrowserFingerprint.getPlaywrightOptions(config)

// 创建隐身上下文
BrowserFingerprint.createStealthContext(browser, customConfig)
```

#### 2. `lib/california-fingerprint.js` - 加州专用指纹库
**功能**: 专门针对加州地区的高精度指纹伪装

**特点**:
- 真实的加州地区硬件配置
- 符合当地人口特征的语言设置
- 准确的太平洋时区和地理坐标
- 支持硅谷、洛杉矶、旧金山等城市

**核心方法**:
```javascript
// 生成加州随机指纹
CaliforniaFingerprint.generateRandomCaliforniaFingerprint()

// 生成多个指纹配置
CaliforniaFingerprint.generateMultipleCaliforniaFingerprints(count)

// 创建加州上下文
CaliforniaFingerprint.createCaliforniaContext(browser, customConfig)

// 获取随机加州位置
CaliforniaFingerprint.getRandomCaliforniaLocation()
```

#### 3. `lib/fingerprint-spoofer.js` - 高级指纹伪装库
**功能**: 功能最完整的高级指纹伪装解决方案

**特点**:
- 支持所有类型的指纹伪装
- 高度可定制化配置
- 完整的 Canvas 和音频指纹处理
- 适用于复杂的检测环境

**核心方法**:
```javascript
// 创建伪装器实例
const spoofer = new FingerprintSpoofer(options)

// 获取初始化脚本
spoofer.getInitScript()

// 应用到页面/上下文
spoofer.applyToPage(page)
spoofer.applyToContext(context)
```
