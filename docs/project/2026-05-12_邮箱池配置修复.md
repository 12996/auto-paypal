# 邮箱池配置修复

## 问题描述

用户反映在调用 `POST /api/admin/products/generate` 接口时，系统使用随机邮箱 `ogwz0ip9ddj6q1t@chiyiyi.cloud` 而不是数据库中的邮箱，尽管 `.env` 文件中设置了 `EMAIL_SOURCE=pool`。

## 根因分析

通过系统化调试发现了两个关键问题：

### 问题1：配置读取逻辑错误
- `.env` 文件中设置了 `EMAIL_SOURCE=pool`
- 但 `product_activator.js` 中的 `runRegistrationProcess()` 函数从**数据库**读取 `email_source` 配置，而不是环境变量
- 数据库中缺少 `email_source` 配置，导致回退到默认值 `'random'`

### 问题2：邮箱池无可用邮箱
- 邮箱池中的邮箱都被标记为 `registered = 1`（已注册）
- 预留邮箱的条件是 `registered = 0`，所以无法预留

## 调用链分析

```
POST /api/admin/products/generate
  ↓
startAdminProductGenerationTask()
  ↓
startProductCreation('')  // 注意：第一个参数是空字符串
  ↓
runRegistrationProcess()
  ↓
emailSource = await store.getAppConfigValue('email_source', '')  // 从数据库读取，不是环境变量
  ↓
childEnv.EMAIL_SOURCE = emailSource  // 传递给子进程
  ↓
register_openai.js 接收到 EMAIL_SOURCE=random
  ↓
生成随机邮箱：ogwz0ip9ddj6q1t@chiyiyi.cloud
```

## 解决方案

### 修复1：设置数据库配置
```javascript
await store.setAppConfigValue('email_source', 'pool');
```

### 修复2：添加可用邮箱到邮箱池
将 `ElveraHernandes05501@outlook.com` 添加到邮箱池，包含：
- Client ID: `9e5f94bc-e8a4-4e73-b8be-63364c29d753`
- Refresh Token: 完整的 OAuth2 刷新令牌
- 状态：`registered = 0, is_active = 1`

## 修改的文件及关键改动

### 数据库配置更改
- `app_config` 表：设置 `email_source = 'pool'`
- `pool_emails` 表：添加新的可用邮箱记录

### 验证结果
- ✅ 数据库配置：`email_source = 'pool'`
- ✅ 邮箱池预留测试：成功预留 `ElveraHernandes05501@outlook.com`
- ✅ 邮箱池释放测试：成功释放预留

## 技术要点

- **配置优先级**：系统优先读取数据库配置，而不是环境变量
- **邮箱池条件**：只有 `is_active = 1 AND registered = 0` 的邮箱才能被预留
- **OAuth2 认证**：邮箱池支持 OAuth2 刷新令牌和密码两种认证方式
