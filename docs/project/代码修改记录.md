## 2. 禁用 IMAP 自动初始化

**文件**: `server/imap-auth.js`

**问题**: 原代码在模块加载时自动初始化 IMAP 连接，导致启动失败

**修改内容**: 注释掉自动初始化代码

```javascript
// 原代码 (已注释)
// initializeImap().catch(err => {
//     console.error('IMAP initialization failed:', err);
// });

// 修改后: 禁用自动初始化，改用直接 OAuth2 方式取件
// IMAP 初始化已禁用 - 使用 mail.chatai.codes OAuth2 直接取件
```

**原因**: 计划使用自己的邮件服务 `mail.chatai.codes` (支持 OAuth2) 替代原有的 `imap.chiyiyi.cloud`

## 3. 修复数据库迁移脚本

**文件**: `server/update-mysql-schema.js`

**修改内容**: 在文件开头添加 dotenv 加载
