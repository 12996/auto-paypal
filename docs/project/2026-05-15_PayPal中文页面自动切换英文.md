# PayPal 中文页面自动切换英文

## 问题/需求描述

PayPal 跳转后可能渲染中文登录/创建账户页，导致后续只等待英文 `Create an Account` 按钮时卡住。

## 解决方案

在 `index.js` 的 PayPal 跳转后、等待 `Create an Account` 前增加语言检测：

- 检测 `html lang`、隐藏 `locale.x`、URL 参数和页面中文关键文案。
- 如果判断为中文页，优先点击页面里的 English 语言入口：
  - `a[data-locale="en_US"]`
  - `a[lang="en"][href*="locale.x=en_US"]`
  - `.scTrack\:unifiedlogin-footer-language_en_US`
  - `a:has-text("English")`
- 切换后继续等待 `Create an Account`。
- 刷新重试后也会再次检查语言。

## 日志策略

默认只输出简洁摘要，避免 PayPal URL 中的 `ba_token`、`token`、`ctxId` 刷屏：

```text
[PayPal Locale] navigation: /agreements/approve country=- locale=-
[PayPal Locale] /signin htmlLang=en country=CN locale=en_US -> 已切换英文
```

需要完整 JSON 时设置：

```bash
DEBUG_PAYPAL_LOCALE=1
```

```bash
node --check index.js
```

并增加一次静态断言检查，确认语言检测函数和调用点已存在。
